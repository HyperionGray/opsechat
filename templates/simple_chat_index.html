⚡ OpSecChat ⚡

Security Features

  • Messages disappear after 3 minutes
  • In-memory only - no disk storage
  • Memory overwritten on message deletion
  • Randomized usernames with color distinction
  • Optional E2E encryption with Web Crypto API
  • Text-only - no media or file sharing
  • Tor hidden service ready

How It Works

  • Click "Create New Chat Room" below
  • Share the room URL with your contacts
  • Chat securely and anonymously
  • Messages auto-delete after 3 minutes
  • Enable E2E encryption in room settings

⚠ Security Reminder

  • Only share room URLs with trusted contacts
  • Use Tor Browser for maximum anonymity
  • Rooms expire after 1 hour of inactivity
  • Do not share sensitive credentials
  • This is for operational security communications only
