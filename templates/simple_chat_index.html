⚡ OpSecChat ⚡

Security Features

  • Messages disappear after 3 minutes
  • In-memory only - no disk storage
  • Memory overwritten on message deletion
  • Explicit closed-roster OpenPGP room bootstrap
  • Signed and encrypted room messages to the full roster
  • Local verification states for known, changed, and verified keys
  • Text-only - no media or file sharing
  • Tor hidden service ready

How It Works

  • Click "Create New Chat Room" below
  • Generate or import your local OpenPGP identity
  • Add every planned member and verify fingerprints out of band
  • Lock epoch 1 before the first room message
  • Share the room URL only after the roster is locked

⚠ Security Reminder

  • Only share room URLs with trusted contacts
  • This alpha release keeps room rosters immutable after bootstrap
  • Use Tor Browser for maximum anonymity
  • Rooms expire after 1 hour of inactivity
  • Do not share sensitive credentials
  • This is for operational security communications only
