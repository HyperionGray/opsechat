## 1. Overview

This Privacy Policy explains how opsechat handles information when you use the service.

opsechat is designed for privacy-preserving communication with an in-memory architecture and no persistent chat or message storage by default.

---

## 2. Data We Intentionally Minimize

We are built to avoid collecting or retaining sensitive content wherever possible.

- Chat messages are held in memory only and auto-expire.
- Burner and ephemeral data use short retention windows.
- No permanent chat transcripts are stored by default.
- No persistent user profile database is required for core chat usage.

---

## 3. Information We May Process

Depending on how the service is used and configured, the system may process:

- Session identifiers generated at runtime
- Service metadata (timestamps, endpoint usage, basic operational counters)
- User-submitted content while it exists in memory
- Abuse reports voluntarily submitted by users

---

## 4. Information We Do Not Seek to Collect

By design, we do not seek to collect:

- Long-term plaintext message archives
- Persistent personal profile data for chat-only usage
- Unnecessary tracking identifiers

---

## 5. Storage and Retention

Retention is intentionally limited:

- Chat messages: default 3 minutes
- Direct messages (DM links): default 1 minute
- Inactive chat rooms: default 1 hour
- Optional technical logs: minimal and retention-limited where enabled

These defaults may change by configuration as part of operations and abuse prevention.

---

## 6. Security Controls

We use layered controls to reduce exposure:

- Content Security Policy and security response headers
- In-memory data lifecycle controls and cleanup loops
- Endpoint rate limiting
- Input validation and sanitization
- Optional client-side encryption features

No system is perfectly secure; users should treat operational security as a shared responsibility.
