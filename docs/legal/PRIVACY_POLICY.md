## 1. Overview

This Privacy Policy explains what information opsechat processes, how long it is retained, and your choices.

opsechat is designed around ephemeral, privacy-preserving communication:

- In-memory data handling
- Automatic expiry of chat and DM content
- Tor-first deployment model
- Minimal metadata exposure

This policy should be read alongside our Terms of Service and Acceptable Use Policy.

---

## 2. Information We Process

### 2.1 Session and Operational Data

To provide core functionality, opsechat may process:

- Random session identifiers
- Temporary room identifiers
- Message payloads while active
- Message timestamps and expiry metadata
- Basic service health/uptime state

### 2.2 User-Provided Content

When you use chat or email features, content is processed in memory to deliver service functionality.

Depending on feature usage, this can include:

- Chat messages
- Direct messages
- Email compose/inbox content in active session state

---

## 3. Data Retention

Opsechat follows an ephemeral retention model by default:

- Chat messages: short-lived, auto-expired
- Direct messages: short-lived, auto-expired
- Session state: temporary and tied to runtime/session context

Content is intended to be removed from memory after expiry events and normal cleanup cycles.

No guarantee is made for absolute instant erasure at the hardware level, but the system is designed to minimize persistence.

---

## 4. Data We Do Not Intend to Collect

By design, opsechat does not aim to build long-term user profiles.

The service is not intended to require:

- Persistent identity accounts (in current implementation)
- Behavioral tracking profiles
- Advertising identifiers
