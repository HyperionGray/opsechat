## 1. Purpose

This Privacy Policy explains what information opsechat processes, how we process it, and your choices regarding that information.

opsechat is designed around privacy and data minimization. The service defaults to in-memory handling and short retention windows for chat and direct-message features.

---

## 2. Information We Process

### 2.1 Information you provide
- Chat message content
- Direct-message content
- Optional email configuration values if email features are used

### 2.2 Information generated during use
- Temporary session identifiers
- Randomized usernames/colors for room display
- Operational metadata such as message timestamps and room activity state

### 2.3 Information not required for core chat usage
- Formal account registration data is not required for basic chat room use in the current release

---

## 3. How Data is Stored

### 3.1 In-memory design
Core chat and direct-message data is stored in application memory rather than durable storage in normal operation.

### 3.2 Automatic expiry
- Chat messages are removed after approximately 3 minutes
- Inactive rooms are removed after approximately 1 hour
- Direct messages are removed after approximately 1 minute

### 3.3 Overwrite on removal
Where implemented, message payload fields are overwritten in memory before cleanup to reduce residual exposure.

## 4. How We Use Information

We process information to:
- deliver chat, direct message, and optional email functionality
- enforce abuse-prevention and operational security controls
- maintain availability, reliability, and basic service health monitoring
- investigate policy violations and illegal activity when required

We do not use private message content for advertising.

## 6. Security Practices

Security controls include:
- transport-level protections based on deployment configuration
- strict response security headers in web responses
- endpoint rate limiting for abuse prevention
- minimized retention windows for sensitive message data

No system can guarantee absolute security. Users should follow strong operational security practices and avoid sharing credentials in chat.
