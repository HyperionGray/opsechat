# Repository Hygiene Automation

## Overview

The daily progress workflow now includes an automated repository hygiene report.
This report is generated by `scripts/repo_hygiene_report.py` and embedded into
the daily issue body so cleanup work can be prioritized consistently.

## What the Report Checks

1. Unfinished work markers in code and workflow files:
   - `TODO`, `FIXME`, `STUB`, `TBD`, `XXX`, `WIP`
   - `NotImplementedError`
2. Duplicate workflow definitions (`.yml` and `.yaml` variants with same stem)
3. Deprecated workflows that should be inactive in `.github/workflows`

The scan intentionally excludes directories that are typically archival or
vendor-heavy (`docs/`, `bak/`, `node_modules/`, `static/`, etc.) to keep the
signal focused on actionable production code and automation config.

## Run Locally

```bash
python scripts/repo_hygiene_report.py --repo-root . --format markdown
```

Write output to a file:

```bash
python scripts/repo_hygiene_report.py --repo-root . --format markdown --output /tmp/repo-hygiene.md
```

JSON output:

```bash
python scripts/repo_hygiene_report.py --repo-root . --format json
```

## CI/Automation Integration

`.github/workflows/daily-continuous-progress.yml` now runs:

1. `python scripts/repo_hygiene_report.py ... --output /tmp/repo-hygiene.md`
2. Embeds `/tmp/repo-hygiene.md` in the daily progress issue body
3. Mentions Copilot with explicit instructions to use the hygiene data

This creates a repeatable feedback loop for unfinished work and repository
cleanup without adding new noisy always-on workflows.
