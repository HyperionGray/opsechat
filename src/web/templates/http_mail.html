How HTTP Mail works:
1. Create an inbox — you get a randomized username and a private inbox key.
2. Share both values only with people you trust to send encrypted text.
3. Your inbox key never needs to leave your browser to decrypt stored ciphertext.
4. There is no mailbox session state. Messages expire after 24 hours and stay in memory only.
