OpSecChat

Secure Chat Rooms

Closed-roster OpenPGP rooms over Tor hidden services. Every message is signed by the sender and encrypted to the full roster. Messages auto-burn after three minutes; nothing touches disk.

Security features

  • Messages disappear after three minutes
  • In-memory only -- no disk storage
  • Memory overwritten on message deletion
  • Closed-roster OpenPGP room bootstrap
  • Signed and encrypted to the full roster
  • Local trust states for known, changed, and verified keys
  • Text-only -- no media or file sharing
  • Tor hidden service ready

How it works

  1. Click Create New Chat Room below
  2. Generate or import your local OpenPGP identity
  3. Add every planned member and verify fingerprints out of band
  4. Lock epoch 1 before the first room message
  5. Share the room URL only after the roster is locked

Create a room

Each room is a fresh, unguessable id. The roster becomes immutable the moment you lock epoch 1, so plan the participant list first.

Security reminder

  • Only share room URLs with trusted contacts
  • Alpha rosters are immutable after bootstrap
  • Use Tor Browser for maximum anonymity
  • Rooms expire after one hour of inactivity
  • Do not share sensitive credentials
