MVP constraints

  • Plain text only for user-authored content.
  • No attachments or media handling in MVP.
  • Ephemeral state only; user messages stay in memory.
  • Short retention windows with explicit destructive cleanup.
  • Restricted services are opt-in and intentionally omitted from the public console.

Compose notes

  • App and Tor run as separate services in a single compose stack.
  • Tor control authentication uses a shared cookie volume between services.
  • No host ports are exposed by default; use the onion service or opt into debug exposure.
  • The stack is intentionally minimal so operators can audit it quickly.
